# 色彩管线、算法与已知局限

## 1. 处理链路

```
输入图（已解码 sRGB；RAW 走 libraw 近似解码）
   │
   ├─ 采样：同位置抽样 → 按亮度 16 层分层 → 丢弃源端过曝/死黑
   │        （同一像素位置必须同时取自源和修后图，否则配对直接毁掉：实测 ΔE 0.6 → 23）
   │
   ├─ 先验：3×3 矩阵 + 偏置，再叠逐通道 17 节点 1D 曲线（线性外推，不发散）
   │
   ├─ 残差：把 (修后 − 先验) 三线性 splat 到 33³ 格点，归一化卷积扩散填空
   │
   ├─ 置信度：格点权重归一化 → 弱证据区回落到先验，不幻觉
   │
   ├─ 平滑 2 遍 + 可选单调约束 → 导出 .cube
   │
   ├─ 分区（可选）：语义分割出软掩膜 → 每个分区在全局 LUT 之上再拟合一层残差
   │
   └─ 应用：三线性插值 → 分区软混合 → 过曝像素原样通过 → 1LSB 抖动 → 输出
```

## 2. 为什么先验必须是「矩阵 + 曲线」

只用 LUT 拟合会在两个方面崩：

- **裸格点拟合**：自然图像只占据色彩空间的一个薄片（实测覆盖 12–45%）。薄片之外的格点没有数据，回落恒等会让整体调子完全对不上。
- **二次多项式先验**：外推时在立方体角落会冲到 [-0.1, 1.1]，导致约 5–9% 的 LUT 体积被压到 0 或 1，等于把大量颜色压死。

「3×3 矩阵 + 1D 曲线」是摄影调色的标准形态（跟 ACES 的思路一致），线性外推不会发散，残差 LUT 只负责补局部细节。

分区块沿用同一结构，只是把先验换成全局 LUT：分区里没出现过的颜色回落到「全局风格」而不是「恒等」，
这样只有天空被改色时，树叶不会因为缺数据而被还原成原样。

## 3. 三线性 vs 四面体

早期版本用四面体插值，理由是教科书上说高饱和区四面体更准。实测两者在本管线上几乎等价：

| 项 | 三线性（当前） | 四面体 |
|---|---|---|
| 1080 万像素耗时 | 3.6 s | 8.0 s |
| 与四面体的最大逐像素差 | 0.0027（≈0.7/255） | — |
| 灰阶中性（max abs a\*/b\*） | 0.789 / 1.873 | 0.789 / 1.873 |
| 4096 级 ramp 残留级数 | 225 级，最大间隔 1 | 225 级，最大间隔 1 |

四面体的 2.2× 耗时来自必须按分支选择 6 个四面体、无法用连续内存 gather 实现。
差异远小于 8bit 量化步长，所以改用 8 次 `np.take` 的连续查表实现，走三线性。

## 4. 先验强度是按数据实测选的

拟合 = 先验（3×3 矩阵 + 逐通道 1D 曲线） + 晶格残差。先验给多少权重，两个方向都有真实案例：

| 素材 | s=1.0 | s=0.5 | s=0.2 | s=0.05 |
|---|---|---|---|---|
| 暗调人像 → 暖调胶片（全片偏暗，色域窄） | **3.87** | 4.54 | 5.44 | 5.97 |
| 只压暗天空（变换集中在高光） | 6.38 | 5.13 | 4.52 | **4.26** |

第一组的 look 只能靠先验表达（暗部到中调的大幅提亮），把先验砍掉就学不到曲线。
第二组的变换是局部性的，晶格自己就能表达，先验抢权重反而和残差打架。

所以固定值是错的，改成一小组候选实测择优：先用较小的探测集算每一档的实际 dE，
取最小的那档。残差经过扩散和平滑，无法完全抵消过强的先验，因此训练误差本身就能区分对错，
不需要额外切验证集。

历史包袱：早先的规则是「先验一旦在立方体角落越界，就把整个立方体按比例缩回」。
这个规则在普通素材上就会误触发 —— 任何抬中间调的 look 都必然在白色角越界 —— 实测 s 被压到 0.022，
0.40 的输入只映射到 0.47（配对要求 0.77），dE 5.69。现在只拦真正的数值爆炸（越界超过 1.5）。

单调约束默认开启：强提亮的 look 会让对角通道在深阴影里出现千分级别的回落（实测 4056 个格点，最差 -0.005），
那是两三个 8bit 台阶的色调反转，单看无所谓，放在暗部渐变里就是色块。开启后全局拟合 dE 不变（3.675 → 3.675）。
分区残差层不做这个约束 —— 它叠在已单调的底图上，压平它的起伏会掉精度（实测 2.17 → 2.92）。

## 5. 分区调色

语义分割用 SegFormer-B0（ADE20K，ONNX，量化版 4.4 MB / fp32 15 MB），
512×512 输入，输出 128×128 概率图，再上采样成软掩膜。

- 置信门限：`p < 0.40` 权重 0，`p > 0.70` 权重 1，中间线性过渡
- 羽化：1.6σ 高斯，避免两种映射交界出现硬轮廓线
- 天空特殊处理：从顶行以 0.22 的低阈值向下连通生长，再只填「大而紧凑」的封闭洞
- 洞填充必须按面积 + 包围盒填充率过滤：只填紧致的洞，否则冬季枯枝（细长、被天空包围）会被一起填成天空，
  实测掩膜覆盖从 0.30 跳到 0.46、树梢整片被染上

实测收益（合成「只压暗天空」的修图对）：

| 方案 | 天空 ΔE | 非天空 ΔE |
|---|---|---|
| 全局单层 LUT | 11.27 | 0.322 |
| 全局 + 天空分区 | **1.50** | **0.324** |

非天空误差不变，说明分区层没有污染其他区域。

## 6. 过曝像素原样通过

渲染末尾对 `max(R,G,B) ≥ 0.97` 的像素做一次向原图的软过渡（0.97→0.999 平滑窗）。

原因是过曝像素没有颜色信息，任何映射都是发明。逆光实测：太阳盘 80% 像素顶在 1.0，
天空分区 LUT 只见过未过曝样本，把盘心推到 0.71 且蓝通道高于红通道，
渲染出来是一块灰蓝色斑，外面套一圈橙光——明显是错的。加保护后太阳恢复成暖白光源，无接缝。

代价：最亮的高饱和高光（单通道顶格）也不再被重映射。色卡实测训练 ΔE 1.15 → 1.21。

判据用的是**最亮通道**而不是最暗通道。试过最暗通道，它只在完全无色的盘心起作用，
盘心会以硬边切成纯白（像贴上去一个白圆盘），而最亮通道能让整个盘面平滑过渡。

`--no-clip-guard` 可以关掉这个行为（例如用户明确要求连过曝区也一起压暗时）。

## 7. 无参考自检与 log 判别

`fit` 要成对样片，`verify` 要有目标图。用户只丢一张图问「这张有没有问题」时两者都答不了，`scripts/imgcheck.py` 补这一块，全部用不需要参考的经典判据。

### measure()

| 量 | 怎么算 | 什么时候报 |
|---|---|---|
| 中位亮度 | Rec.709 luma 的 p50 | 只用于前后对比，不判绝对高低 |
| 黑位 | luma 的 p0.5 | 抬到 0.06 以上才算可疑 |
| 死白 | `min(R,G,B) ≥ 0.985` 的像素比 | > 3% |
| 死黑 | `max(R,G,B) ≤ 0.015` 的像素比 | 绝对 > 10%（剪影、夜景合法）；渲染新增 > 1.5pp |
| 色偏 | Shades-of-Gray，Minkowski p=6，排除过曝像素 | > 0.6 档，且画面有 ≥2% 中性像素 |
| 中性像素偏移 | chroma < 10 的像素的 b* 中位数 | \|b*\| > 14 |
| 肤色 | YCbCr locus + HSL 色相 8–45°，**仅在分割到人时判** | 偏离 20° 超过 12° |
| 色彩丰富度 | Hasler–Süsstrunk | 无目标值，仅 < 4 或 > 110 |

每个门限都是被真实素材逼出来的。实测一张日落街景，单靠 YCbCr 肤色 locus 会把 **30% 画面**判成皮肤（建筑、阳光、雨棚）；一张阴天街景的 p50 是 0.65，已经踩在「log 中位偏高」的特征上。所以每项都要第二条证据（有人 / 有中性像素），宁可不报。肤色这条还额外借了分割的 `person_pct`：ADE20K 会把特写猫标成 person，靠「person 区域内肤色占比 < 8% 就不算人」挡掉。

### transfer()

读直方图形状，不读 EXIF（图到这一步通常已是 PNG 或 libraw 渲染结果）：

- `black lifted`：p0.5 > 0.055
- `highlight held back`：p99.9 < 0.88
- `narrow range`：p99.9 − p0.5 < 0.72
- `desaturated`：平均饱和 < 0.22

≥3 项判 `log`，2 项判 `ambiguous`，其余 `display`。

用 p0.5 / p99.9 而不是 p1 / p99：逆光片子里被裁掉的太阳常常不到 1% 像素，用 p99 会把一张正常显示参考的日落判成「高光收着」。另一条「中位在动态范围内的相对位置」信号被删掉了——正常曝光的照片该值是 0.64，和 log 无法区分，留着只会误报。

实测：日落 RAW、正午街景、室内猫、一张压过天空的成片全部判 `display`；把街景做一次 log 编码并降饱和后，四项全中判 `log`。

## 8. 指标怎么算

- ΔE2000：标准 CIEDE2000 公式，在 CIELAB D65 下计算，逐像素取均值 / 95 分位 / 最大值
- 采样步长 `stride=7`，即每 49 个像素取 1 个，够稳定也够快
- `geometry_preserved` 只检查尺寸一致。插值不改变几何，这个字段恒为 true，用来兜住管线 bug（比如中间做了 resize）
- 断层检测：把 4096 级灰阶 ramp 过一遍 LUT，统计残留的 8bit 级数与最大间隔。正常应为 256 级、最大间隔 1
- 风格距离：在一组「探针色」上（25 级灰阶 + 18×3×4 HSV 网格 + 肤色/天空/黑色锚点，约 220 色）
  比较两个 LUT 的平均 ΔE2000，< 1.5 视为同一风格。用于判断新素材该新建风格还是并入已有风格。

## 9. 已知局限

| 局限 | 影响 | 缓解方式 |
|---|---|---|
| **掩膜只有 128×128 分辨率** | 细于约 1/128 画幅的结构（枯枝、电线）会被算进所在分区 | 这些结构通常接近剪影，被压暗看不出；真要精确请用外部蒙版 |
| **分区层仍是像素颜色函数** | 同一颜色在不同区域无法不同处理，只能靠掩膜区分区域 | 分区 LUT 无法合并成单个 `.cube`，导出时用 `export --full` |
| **RAW 是近似解码** | libraw + 相机白平衡 + 通用矩阵，无相机 DCP，与 LR 渲染有可见差异 | 需要精确交付时导 16bit TIFF；工具会输出 `raw_note` 提示 |
| **`ref` 模式精度有限** | 实测 ΔE ≈ 4，只对齐 Lab 分布，不管内容 | 用来冷启动，后续用 `fit` 校正 |
| **语义盲** | 参考图里的大面积蓝天会被无差别转移到人像上 | 用 `--skin` 保护肤色；必要时缩到同场景参考图 |
| **8bit 输出** | 深色渐变仍有理论断层风险 | 默认加抖动；要求 16bit 时用 `--bits 16` 输出 TIFF（需 tifffile） |
| **`prior_shrink` 由数据决定** | 先验强度在 1.0/0.5/0.2/0.05 里实测择优；两个方向都有真实失败案例，详见 §4 | 看 `prior_trials` 里各档的 dE，差距很小说明这个决策不敏感 |
| **LUT 只在学过的明暗范围内可信** | 超出源图 p99 的像素靠线性外推，高光会顶穿（实测中位 0.55 的片套完变成 0.95） | `apply` 的 `look` 会报出来；收 `--strength`，或同光比连拍用 `--match-key on` |
| **主体比背景暗时无处可躲** | 全局单调映射无法同时满足「主体到位」和「背景不过曝」 | 保主体（默认）；要背景也压下去只能做局部调整 |
| **过曝区不参与风格** | 大面积过曝的画面会看起来「没调」 | 这是有意的：能救的高光才救，救不了的不要发明 |

## 10. 性能基线

单张 3474×2314（804 万像素）RAW：

| 阶段 | 耗时 |
|---|---|
| libraw 解码 | 0.58 s |
| 语义分割（量化模型，CPU） | 0.42 s |
| LUT 渲染（含分区混合 + 过曝保护） | 3.6 s |

内存峰值由 `chunk_rows` 控制，默认 128 行，与图像高度无关。

## 11. 调参建议

| 现象 | 调整 |
|---|---|
| ΔE 偏高（>4） | 检查配对是否对齐（同名不同图会毁掉训练）；确认只改了颜色没动内容 |
| 风格太强 | `apply --strength 0.6–0.8`，不重拟合 |
| 分区效果过冲 | `--region-strength 0.6–0.8`，或提高 `--min-region-pixels` 让小区块不参与 |
| 分区没生效 | 看 `regions.active`；为空说明该区域像素太少被跳过 |
| 肤色被带偏 | `ref` 时把 `--skin` 调到 0.3；`fit` 时增加人像对 |
| 高光丢细节 | 检查 `lut_clipped_pct_observed`；根源通常是训练对本身就把高光压死了 |
| 出现色相翻转 | 默认已强制单调；若仍出现，把 `--smooth` 调到 3 |
| 套完整体发白 | 看 `look.median_luma`；`--strength 0.7` 或 `--match-key on`（仅同光比） |
| 套完主体发黑 | 关掉 `--match-key`；这张片主体比背景暗，而参考片反过来 |
| LUT 体积太大 | 从 33³ 降到 17³（质量会掉，仅用于预览） |
| 想更精细 | `--size 65`，但需要更多修图对支撑覆盖率 |
| 自检告警太多 | 先看是不是夜拍 / 日落 / 雪景这类合法极端场景；`warnings` 是建议不是判据 |
| `fit` 报 `input_guard` | 确认素材来源：log 必须先转色；褪色风格成片可以忽略（`blocking: false`） |

## 12. 与生成式方案的分界

本管线只做一件事：把输入颜色确定性地映射到输出颜色。

- 输出分辨率 = 输入分辨率，不重采样
- 结构相似度恒为 1.0（连像素位置都不动）
- 同一输入 + 同一 LUT = 同一输出，可复现、可审计
- 无法改变光照方向、无法增删物体、无法重绘纹理

需要这些能力时，那是另一个模型的事，不要把两件事混在一个管线里——混了就没法保证保真。
